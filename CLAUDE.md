# Working agreement

## Project tracker mode (always on)

In every project in this repo, keep a running tracker of the whole task so progress can be followed through the chat:

- At the start of any project or multi-step task, break the work into sections.
- Give each section a status: ✅ Done, 🔄 In progress, ⏳ Pending, ⏭️ Skipped, or ⛔ Blocked.
- Every skipped or blocked section needs a note saying why.
- Keep exactly one section in progress while working.
- End each reply about the project with the tracker: a progress bar, a table of sections (status and notes), and a one-line count of each status.
- If the `project-tracker` plugin is installed, keep it updated with its `mcp__project-tracker__update` tool. It also shows the tracker in a side pane and above the prompt, and `/tracker` brings it up.
- Skip the tracker for one-off questions that aren't project work.
