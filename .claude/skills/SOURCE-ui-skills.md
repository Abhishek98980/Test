# Skills from ibelick/ui-skills

These skill folders are copies of all 8 skills in the `skills/` folder of https://github.com/ibelick/ui-skills at commit `9a0cb1e610e3a1a4f0f2723bf2e7680ac1b89cf5`:

- `baseline-ui` (assumes Tailwind CSS and React, so it does not fit the Blocksy and Elementor site)
- `component-canvas`
- `create-design-md`
- `fixing-accessibility`
- `fixing-metadata`
- `fixing-motion-performance`
- `improve-ui`
- `ui-skills-root` (fetches more skills with `npx ui-skills`, which needs network access to ui-skills.com)

They are plain copies, so they do not update themselves. To update, re-copy the folders from a newer commit of that repo.
