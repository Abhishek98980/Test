# Skills from mattpocock/skills

The skill folders here are copies of the 27 published skills (the `engineering` and `productivity` sets listed in its `.claude-plugin/plugin.json`) from https://github.com/mattpocock/skills at commit `49dd158d1076134a641b33efb035946536778336` (plugin version 1.3.1).

They are plain copies, so they do not update themselves. To update, re-copy the folders from a newer commit of that repo.

Run `/setup-matt-pocock-skills` once in this repo before using the engineering skills.
