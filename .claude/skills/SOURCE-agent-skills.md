# Skills from vercel-labs/agent-skills

These skill folders are copies of all 9 skills in the `skills/` folder of https://github.com/vercel-labs/agent-skills at commit `063bee94c3f4df8453406c830b0a7df0f2860278`:

- `composition-patterns`: React component composition patterns
- `deploy-to-vercel`: deploys a project to Vercel; its `resources/deploy.sh` uploads the project to Vercel's deploy service when the skill runs
- `react-best-practices`: React and Next.js performance rules
- `react-native-skills`: React Native and Expo guidance
- `react-view-transitions`: React View Transition API animations
- `vercel-cli-with-tokens`: Vercel CLI with access tokens
- `vercel-optimize`: cost and performance review of a deployed Vercel project (Node scripts under `scripts/` and `lib/`)
- `web-design-guidelines`: reviews UI code against Vercel's Web Interface Guidelines, fetched from raw.githubusercontent.com when it runs
- `writing-guidelines`: reviews prose against Vercel's writing guidelines, fetched the same way

They are plain copies, so they do not update themselves. To update, re-copy the folders from a newer commit of that repo.
