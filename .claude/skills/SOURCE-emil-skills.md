# Skills from emilkowalski/skills

These skill folders are copies of all 15 skills in the `skills/` folder of https://github.com/emilkowalski/skills at commit `2d228630ba1446365f614a108cb8252f1feda202`.

One change from upstream: its `prototype` skill is installed as `emil-prototype` (folder and `name:`), because `prototype` from mattpocock/skills already uses that name here. Run it with `/emil-prototype`.

The skills: `animate`, `animate-expo`, `animation-performance`, `animation-vocabulary`, `apple-design`, `ask-sonner`, `break-ui`, `emil-design-eng`, `emil-prototype`, `find-animation-opportunities`, `improve-animations`, `mobile-native`, `pick-ui-library`, `review-animations`, `write-swift`. Of these, `emil-prototype`, `pick-ui-library` and `review-animations` only run when typed as a command.

They are plain copies, so they do not update themselves. To update, re-copy the folders from a newer commit of that repo, and rename `prototype` again.
